# 한국 시간 기준 발행 일정

| 요일 | 오전 | 12:00 |
|---|---|---|
| 월 | - | 해외 경제 영상 번역 |
| 화 | 월요일 미국장 요약 | - |
| 수 | 화요일 미국장 요약 | - |
| 목 | 수요일 미국장 요약 | - |
| 금 | 목요일 미국장 요약 | - |
| 토 | 금요일 미국장 요약 | 해외 경제 영상 번역 |
| 일 | - | 해외 경제 영상 번역 |

시황 작업은 06:20 KST에 시작한다. 직전 미국장이 휴장이라면 시황 영상을 만들지 않고, 준비 완료 상태인 해외 영상 재고 한 편을 같은 오전 슬롯에 발행한다.

해외 영상은 `ready` 상태만 발행 큐에 들어간다. 주제·원본 3편·썸네일을 확정한 뒤 자막 번역, 클립 구성, 해설 TTS, 합성, 롱폼, 숏폼 6편까지 먼저 생성해 재고로 쌓는다. 테스트 항목은 `upload_blocked=true`로 두어 예약 작업에서도 업로드되지 않는다.

재고 목표는 최소 3편, 권장 6편이다. 월·토·일 정규 발행 외에 미국장 휴장 대체분을 고려한 수량이다.
