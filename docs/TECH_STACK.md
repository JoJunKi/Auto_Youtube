# Technology Stack

## 대본 생성

입력은 원문 전체가 아니라 검증 가능한 `StoryPacket`입니다. Packet에는 뉴스 제목,
근거 문장, 주제, 관련 티커, 정규장 종가 등락, 시간외 등락이 들어갑니다. LLM은 이를
바탕으로 A가 설명하고 B가 질문하는 친구 대화 형식의 초안을 만듭니다.

LLM 출력의 가격 숫자는 그대로 신뢰하지 않습니다. 후처리 코드가 회차별 확정 가격
snapshot으로 문장을 다시 작성하고 티커·숫자·방향을 검사합니다. 운영 환경에 따라
API 모델 또는 로그인된 CLI 백엔드를 선택할 수 있도록 분리합니다.

## TTS

기본 모델은 `Qwen3-TTS 0.6B Base`의 Voice Clone 모드입니다.

- A: 설명 역할의 고정 음색
- B: 질문 역할의 고정 음색
- 같은 영상 안에서 A 대사끼리, B 대사끼리 동일한 참조 음성을 사용
- 문장별 합성 후 타임라인에 배치
- 말하기 속도와 문장 간 간격은 렌더 단계에서 조절

`GPT-SoVITS`는 향후 파인튜닝과 더 빠른 생성이 필요할 때 교체 가능한 후보로 둡니다.
참조 음성 자체는 저장소에 포함하지 않습니다.

## 시각 요소와 립싱크

- 차트·지수판·썸네일: Python과 Pillow
- 입 모양 추출: `Rhubarb Lip Sync`
- 영상·음성·자막 결합: `FFmpeg`
- 캐릭터: 화자별 닫힌 입/열린 입 프레임을 립싱크 타임라인에 맞춰 교체
- 화면 구성: 차트 구간과 캐릭터 구간을 대본 태그에 맞춰 전환

## 수집과 시장 데이터

- Telegram: 증분 수집과 마지막 수집 지점 저장
- 뉴스 웹 소스: 중요도·조회수·출처 유형을 보존
- YouTube: 비교 분석용 채널의 자동 자막과 메타데이터 수집
- 가격: 정규장 종가와 시간외 가격을 서로 다른 필드로 저장

실제 채널명, 계정 식별자, 세션 파일과 원문 DB는 공개하지 않습니다.

## 게시

- YouTube Data API: 롱폼·Shorts 영상, 제목, 설명, 태그, 공개 상태, 썸네일
- Instagram Graph API: Reels 게시와 게시 결과 확인
- 게시 전 상태를 기록해 재시도 시 중복 업로드를 방지

## 자동 실행

Windows Task Scheduler가 장 마감 후 설정된 시각에 파이프라인을 실행합니다. 각 단계의
시작·종료 시각, 결과 파일, 게시 URL을 영수증으로 남기며 실패한 단계부터 재개합니다.
